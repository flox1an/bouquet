Playlist parsing depth

Accepted: v1 uses active-profile-authored events, with a future “global search” extension point.

HLS expansion model
master.m3u8 blob
variant 1080p playlist
init.mp4
segment-001.m4s … segment-N.m4s
variant 720p playlist
nested media playlist / iframe playlist / future HLS tags
A

Eager full expansion

Fetch every detected playlist immediately and build complete tree. Best grouping; more network.

B

Lazy expansion

Show playlist roots first; fetch children when expanded. Faster initial view; incomplete counts until open.

C

Bounded eager expansion

Eager parse referenced playlists with concurrency/depth limits, mark truncated/failed nodes explicitly.

Recommendation: C. It gives useful group-level operations while avoiding runaway nested fetches. UI can still lazy-refresh a truncated node.
